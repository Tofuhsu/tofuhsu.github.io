# Jeff Hsu — Software Engineering Portfolio

Minimal personal portfolio website for Jeff (Hsuan-Fu) Hsu, built with semantic HTML and responsive CSS.

## Local preview

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.

## Deployment

The repository is designed for GitHub Pages. For the account-level URL, name the repository `tofuhsu.github.io`, push the files to the `main` branch, and enable Pages from the repository root.
